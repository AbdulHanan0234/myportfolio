## 🚀 About This Portfolio

This is my personal portfolio — a fully responsive, single-page React application that showcases who I am, the projects I've built, and the technologies I work with. It features a smooth animated hero section, a skills showcase, project cards with live demo links, and a working contact form.

## ✨ Features

- 🎨 **Animated Hero Section** — dynamic typewriter roles over an animated background
- 🧩 **Component-Based Architecture** — clean, reusable, and maintainable React components
- 📱 **Fully Responsive** — optimized layout across desktop, tablet, and mobile
- 🌗 **Custom Theming** — consistent design system powered by styled-components & MUI
- 📬 **Working Contact Form** — email delivery integrated via EmailJS
- ⚡ **Blazing Fast** — built with Vite for instant dev feedback and optimized production builds
- 🔗 **Projects with Live Demos** — every project links to its GitHub repo and deployed app

## ⚙️ Getting Started

Want to run this portfolio locally?

```bash
# 1. Clone the repository
git clone https://github.com/AbdulHanan0234/myportfolio.git

# 2. Navigate to the project directory
cd myportfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be available at `http://localhost:5173`.

### 📜 Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the development server with hot reload |
| `npm run build` | Create an optimized production build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint across the codebase |
